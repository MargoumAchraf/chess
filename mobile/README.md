## Project Showcase: Sky Map – An Interactive Astronomy App Built with Flutter 

I'm excited to share one of my latest mobile development projects: **Sky Map**, a Flutter application that allows users to explore the night sky in real time by simply pointing their phone toward the sky.

The objective of this project was to combine mobile sensors, astronomy, and real-time rendering to create an interactive experience that accurately displays celestial objects based on the user's location and device orientation.

### 🌟 What the application does

📍 **Real-time Location Detection**

* Uses the device's GPS to determine the user's geographic position.
* Adapts the visible sky according to the user's latitude and longitude.

📱 **Device Orientation**

* Integrates the accelerometer and magnetometer to detect how the phone is positioned.
* As the device moves, the sky map updates instantly, creating a natural "window into the sky."

⭐ **Live Sky Rendering**

* Continuously redraws the sky more than **10 times per second**, ensuring smooth and responsive movement.
* Displays celestial objects on a black canvas for an immersive viewing experience.

🪐 **Celestial Objects**
The application includes:

* All planets of the Solar System
* ☀️ The Sun
* 🌙 The Moon
* Multiple constellations
* Additional astronomical information retrieved from a public API

ℹ️ **Interactive Experience**
Users can tap on any celestial object to view information such as its name and a brief description, making the application both educational and interactive.

###  Technologies Used

* Flutter
* Dart
* Provider for state management
